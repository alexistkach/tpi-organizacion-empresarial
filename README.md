## Descripción

Proyecto desarrollado para el Trabajo Práctico Integrador.

El sistema busca registrar ventas, actualizar automáticamente el inventario y generar alertas de reposición cuando se alcanza el stock mínimo.

## Entregas

- Entrega 1: Análisis Organizacional
- Entrega 2: Planeación del Proyecto
- Entrega 3: Estructura Formal y Diseño de Datos
- Entrega 4: Procesos, Trabajo Colaborativo y Control Integrador
